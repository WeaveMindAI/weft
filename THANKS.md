# Thank you

weft is built in the open, and this page is where we keep the names of the
people who helped. If you are on it and would rather not be, or you want a
different name or a link, email contact@weavemind.ai and we will change it.

## Supporters

People funding the work through [Ko-fi](https://ko-fi.com/quentin101010).



If you chip in, tell us in [Discord](https://discord.com/invite/FGwNu6mDkU) or on the Ko-fi message and say how you would like to be listed, with a link if you want one. Say nothing and we leave you off, because we are not going to put your name on a public page without asking.

## Contributors

GitHub already keeps the code list, and it is [here](https://github.com/WeaveMindAI/weft/graphs/contributors). Here we will add people that have helped with a non code improvement like a discussion, a security report, a contribution to the community, a shoutout on social that spread the language... If you'd like to be added you can contact us at contact@weavemind.ai.


## Projects we lean on

[Kubernetes](https://kubernetes.io/), [Docker](https://www.docker.com/),
[kind](https://kind.sigs.k8s.io/), [Postgres](https://www.postgresql.org/),
[Svelte](https://svelte.dev/) and [mdBook](https://rust-lang.github.io/mdBook/).
